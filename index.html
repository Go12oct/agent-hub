Why Agent Hub

Local first

A small daemon on your PC reads agent transcripts directly. Nothing is uploaded to a hosted service.

Phone-ready

Pair the Android app with a QR code and follow every session over your LAN or Tailscale.

Many agents

Codex CLI and desktop, Claude Code with hooks, Antigravity, and Devin through its API.

Push alerts

Optional ntfy notifications when a session needs input, finishes, or errors.

Quick start (Windows)

  1. Install Node.js 22+ (LTS).
  2. Download agent-hub-windows.zip from the releases, extract it, and run the installer: 
    Set-ExecutionPolicy -Scope Process Bypass
.\agent-hub\scripts\install.ps1
  3. Scan the QR code it prints with the Agent Hub Android app, or open http://localhost:4747 in your browser.
  4. Optional: agent-hub config set devinApiKey apk_user_... and agent-hub config set ntfy.topic <topic>
